2. Create `src/tui/mod.rs`:
   - Declare submodules: `mod app; mod event; mod ui; mod views; mod widgets;`
   - Implement `pub fn run() -> anyhow::Result<()>` that:
     a. Installs panic hook (saves original, restores terminal before panic)
     b. Calls `init_terminal()` to enter raw mode + alternate screen
     c. Creates `App::new()` loading contacts
     d. Runs event loop: draw -> poll(250ms) -> read key -> handle_key -> update
     e. Calls `restore_terminal()` on exit
   - Implement `fn init_terminal()` and `fn restore_terminal()` using ratatui::crossterm

3. Create `src/tui/app.rs`:
   ```rust
   pub enum Screen {
       ContactList,
       ContactDetail(usize),  // index into contacts vec
       FollowUpDashboard,
   }

   pub enum InputMode {
       Normal,
       Search,
       LogInteraction,
   }

   pub enum Message {
       Quit,
       SelectNext,
       SelectPrev,
       Enter,
       Back,
       StartSearch,
       SearchInput(char),
       SearchBackspace,
       SearchConfirm,
       SearchClear,
       SwitchToDashboard,
       SwitchToList,
       StartLog,
       SubmitLog { interaction_type: String, summary: String },
       CancelModal,
   }

   pub struct App {
       pub contacts: Vec<ContactFile>,
       pub filtered: Vec<usize>,
       pub screen: Screen,
       pub input_mode: InputMode,
       pub search_query: String,
       pub table_state: TableState,
       pub running: bool,
       pub crm_root: PathBuf,
   }
   ```
   - `App::new()` calls `store::find_crm_root()` then `store::load_all_contacts()`, initializes `filtered` to all indices, sets screen to ContactList, input_mode to Normal
   - `App::update(msg: Message)` handles all messages with match. For now implement: Quit (set running=false), SelectNext/SelectPrev (update table_state selection), Enter (switch to ContactDetail if on list), Back (switch to ContactList). Leave search/dashboard/log arms as stubs that do nothing yet.
   - `App::filter_contacts()` method: if search_query is empty, filtered = all indices; else filter by name/company/tags containing lowercase query. Call this after search changes.

4. Create `src/tui/event.rs`:
   - `pub fn handle_key(app: &App, key: KeyEvent) -> Option<Message>` that maps keys based on app.screen and app.input_mode:
     - Normal mode on ContactList: q->Quit, j/Down->SelectNext, k/Up->SelectPrev, Enter->Enter, '/''->StartSearch, d->SwitchToDashboard, l->StartLog
     - Normal mode on ContactDetail: q->Quit, Esc/Backspace->Back, l->StartLog
     - Normal mode on FollowUpDashboard: q->Quit, Esc->SwitchToList, j/Down->SelectNext, k/Up->SelectPrev
     - Search mode: Esc->SearchClear, Enter->SearchConfirm, Backspace->SearchBackspace, char->SearchInput(c)

5. Create `src/tui/ui.rs`:
   - `pub fn draw(frame: &mut Frame, app: &mut App)` that matches app.screen and delegates to view functions
   - For now: ContactList -> views::contact_list::draw_contact_list(), others -> placeholder Paragraph("Coming soon")
