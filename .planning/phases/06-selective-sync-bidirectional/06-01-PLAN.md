  <behavior>
    - SyncFilter::default() returns empty tags/statuses (matches all contacts)
    - SyncFilter::is_empty() returns true when both tags and statuses are empty
    - SyncFilter::matches() returns true for any contact when filter is empty (FILT-04)
    - SyncFilter::matches() returns true when contact has at least one matching tag
    - SyncFilter::matches() returns false when contact has no matching tags (and tags filter is non-empty)
    - SyncFilter::matches() returns true when contact status matches (kebab-case comparison)
    - SyncFilter::matches() handles contact with no status (None) -- passes if statuses filter is empty, fails otherwise
    - SyncFilter::from_config_and_cli() uses CLI values when provided, falls back to config values
    - SyncConfig deserializes from TOML with push_filters and pull_filters sections (both optional, default empty)
    - SyncConfig deserializes from legacy TOML with only apple_id (backward compatible)
    - load_sync_config() reads and parses sync.toml into SyncConfig
    - store_credentials() writes valid TOML that the toml crate can parse back
