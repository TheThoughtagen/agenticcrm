    1. Add a `fn next_follow_up(from_date: NaiveDate, cadence: &str) -> Result<Option<NaiveDate>>` function in log.rs (or a shared cadence module if desired, but log.rs is fine since only log uses it):
       - Empty cadence: return Ok(None)
       - "weekly": from_date + 7 days
       - "biweekly" or "bi-weekly": from_date + 14 days
       - "monthly": from_date.checked_add_months(Months::new(1))

       - "yearly" or "annually": from_date.checked_add_months(Months::new(12))
       - Unknown: bail!("Unknown cadence: '{cadence}'. Supported: weekly, biweekly, monthly, quarterly, yearly")
       - Use `chrono::{Duration, Months}` for arithmetic.

       - Do NOT use `store::write_contact` (which would re-derive path from slug). Write to `cf.path` directly since the file already exists.
       - Accept `format: &OutputFormat` parameter, output result via `format::output`.
