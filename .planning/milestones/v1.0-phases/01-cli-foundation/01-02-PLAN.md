  <name>Task 1: Add edit command</name>
  <files>src/commands/edit.rs, src/commands/mod.rs, src/main.rs, Cargo.toml</files>
  <action>
    1. Add `dialoguer = "0.11"` to Cargo.toml dependencies.

    2. Create `src/commands/edit.rs`:
       - Command signature: `acrm edit "name" --set key=value [--set key2=value2 ...]`
       - Use `--set` (repeatable) with `key=value` format where key matches YAML field name exactly (snake_case). This avoids needing 30+ individual flags.
       - For array fields (email, phone, address, aliases, interests, family, tags): parse comma-separated values from the value part. E.g., `--set tags=rust,cli,bay-area`.
       - Implementation:
         a. Find single contact by name (use existing partial match pattern from show.rs/log.rs — extract to a helper `find_single_contact` in store.rs or a shared util).
         b. For each `--set key=value`:
            - Detect if key is an array field (check against known list: email, phone, address, aliases, interests, family, tags).
            - If array: split value on commas, trim whitespace, call `frontmatter::update_array_field`.
            - If scalar: call `frontmatter::update_field`.
         c. Re-parse the updated raw_frontmatter via serde_yaml to get updated Contact struct.
         d. Call `validation::validate_contact` on the updated Contact. If errors, print them and abort (don't write).
         e. Write the updated file using `store::write_contact` (or direct fs::write since path already exists).
         f. Output result using `format::output`.
       - The `run` function takes `(name: &str, sets: &[String], format: &OutputFormat)`.

    3. Add `pub mod edit;` to `src/commands/mod.rs`.

    4. Add `Edit` variant to `Commands` enum in `src/main.rs`:
       ```rust
       Edit {
           name: String,
           #[arg(short, long = "set", num_args = 1)]
           sets: Vec<String>,
       },
       ```
       Wire to `commands::edit::run(&name, &sets, &cli.format)`.

    5. Extract the "find single contact by partial name" pattern (used in show.rs, log.rs, and now edit.rs) into a shared helper. Add `pub fn find_single_contact(contacts: Vec<ContactFile>, name: &str) -> Result<ContactFile>` to `store.rs`. Refactor show.rs and log.rs to use it too.

<task type="auto">
  <name>Task 2: Add delete and archive commands</name>
  <files>src/commands/delete.rs, src/commands/archive.rs, src/commands/mod.rs, src/main.rs</files>
  <action>
    1. Create `src/commands/delete.rs`:
       - Command: `acrm delete "name" [--yes]`
       - Find single contact using `store::find_single_contact`.
       - If `--yes` not passed: use `dialoguer::Confirm` to prompt `"Delete {name}? This cannot be undone."` with default false.
       - If confirmed (or --yes): `std::fs::remove_file(&cf.path)`.
       - Output result (deleted contact name + path) using `format::output`.
       - `run(name: &str, yes: bool, format: &OutputFormat) -> Result<()>`

    2. Create `src/commands/archive.rs` with two public functions:
       - `pub fn run_archive(name: &str, format: &OutputFormat) -> Result<()>`:
         a. Find single contact.
         b. Update raw_frontmatter: `frontmatter::update_field(&cf.raw_frontmatter, "status", "archived")`.
         c. Create `archive/` directory if it doesn't exist (`std::fs::create_dir_all`).
         d. Write updated content (`---\n{raw_frontmatter}---\n\n{body}`) to `archive/{filename}`.
         e. Remove original file from `contacts/`.
         f. Output result using `format::output`.

       - `pub fn run_unarchive(name: &str, format: &OutputFormat) -> Result<()>`:
         a. Load contacts from `archive/` directory (use walkdir similar to load_all_contacts but targeting archive/).
         b. Find single contact by name match.
         c. Update raw_frontmatter: `frontmatter::update_field(&cf.raw_frontmatter, "status", "active")`.
         d. Write to `contacts/{filename}`.
         e. Remove from `archive/`.
         f. Output result.

    3. Add `pub mod delete; pub mod archive;` to `src/commands/mod.rs`.

    4. Add to `Commands` enum in `src/main.rs`:
       ```rust
       Delete {
           name: String,
           #[arg(short, long)]
           yes: bool,
       },
       Archive {
           name: String,
       },
       Unarchive {
           name: String,
       },
       ```
       Wire each to its run function with `&cli.format`.
  </action>
